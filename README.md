# JBBM Infraservices - Website

Professional facility services website built with HTML, CSS, and JavaScript.

## Folder Structure
```
JBBM Infraservices/
├── index.html              # Home page
├── services.html           # Services page
├── about.html              # About Us (Mission, Vision, Goals)
├── contact.html            # Contact Us page (with form)
├── gallery.html            # Gallery page
├── css/
│   └── style.css           # All styles (light theme)
├── js/
│   └── main.js             # Slider, nav, form, go-to-top, filters
└── README.md
```

## Images (placeholders used)
The site currently uses `placehold.co` placeholder images so it works immediately.  
To use your own images, create these folders and replace the `src` attributes:

```
images/
├── slider/          # 4 service slider images (index.html)
└── gallery/         # Gallery images (gallery.html)
```

## Key Features
- 5 pages: Home, Services, About Us, Contact Us, Gallery
- About Us includes **Mission, Vision, and Goals** subsections
- Home page summarizes all pages with a 4-image service slider (auto-play, visible first, then scroll content)
- Contact form with success feedback
- WhatsApp icon (floating + in navbar)
- Go to Top icon (floating + button)
- Light theme, professional styling, responsive design
- Font Awesome icons

## How to Run
Open `index.html` in any web browser. No build step or server required.

## Contact Data (placeholder)
Update phone numbers, email, and address in all HTML files (`tel:`, `mailto:`, WhatsApp links `wa.me/...`) with your real details before publishing.
